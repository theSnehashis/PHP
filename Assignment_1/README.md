# Assignment 1 — PHP With MySQL

This folder contains the programs and practical exercises for **Assignment 1** of the PHP With MySQL coursework.

## 📚 Assignment Information

* **Subject:** PHP With MySQL
* **Assignment:** 1
* **Total Questions:** 17
* **Language:** PHP
* **Database:** Not required for the questions in this assignment

## 📋 Questions

### Q1 — PHP Version and Configuration

Write a PHP script to get the PHP version and configuration information.

### Q2 — User Name Form

Create a simple HTML form that accepts the user's name and displays the name using a PHP `echo` statement.

### Q3 — Client IP Address

Write a PHP script to get the client's IP address.

### Q4 — Browser Detection

Write a simple PHP browser detection script that displays the user's User-Agent information.

### Q5 — Current File Name

Write a PHP script to get the current file name.

### Q6 — URL Components

Write a PHP script to return the components of the following URL:

```text
https://www.w3resource.com/php-exercises/php-basic-exercises.php
```

### Q7 — HTTP or HTTPS

Write a PHP script to check whether the page is being called using `https` or `http`.

### Q8 — Page Redirection

Write a PHP script to redirect a user to a different page.

### Q9 — Email Validation

Write a simple PHP program to check whether email addresses are valid.

### Q10 — Display Strings and Values

Write a PHP script to display strings and values within a table.

### Q11 — Operating System Information

Write a PHP script to get information about the operating system on which PHP is running.

### Q12 — Last Occurred Error

Write a PHP script to get the last occurred PHP error.

### Q13 — Even or Odd

Create a user input page that accepts a number and determines whether the number is even or odd.

### Q14 — Circle Area and Circumference

Create a user input page that accepts the radius of a circle and calculates:

* Area
* Circumference

### Q15 — Student Grade

Create a user input page that calculates the student's grade based on marks.

The specified conditions are:

| Marks                | Result    |
| -------------------- | --------- |
| Above 800 and ≤ 1000 | Class I   |
| Above 600 and ≤ 800  | Class II  |
| Above 400 and ≤ 600  | Class III |
| Below 400            | Fail      |

### Q16 — Search Word Count

Create a user input page where the user provides:

* A paragraph
* A search word

The PHP program should count the occurrences of the search word in the paragraph.

### Q17 — User Registration

Create a registration page containing:

* Full Name
* Date of Birth
* Email ID
* Mobile
* Agree to Terms and Conditions
* Submit button

Validation requirements:

* Full name must contain two words.
* Date of birth must indicate an age above 18.
* Email must be valid.
* Mobile number must contain 10 digits.
* Terms and conditions must be checked.

If all conditions are satisfied:

```text
successful registration
```

Otherwise, display an appropriate error message.

## ▶️ Running the Assignment

Place the repository inside the XAMPP `htdocs` directory:

```text
C:\xampp\htdocs\PHP
```

Start **Apache** from the XAMPP Control Panel.

Then access the required question through:

```text
http://localhost/PHP/Assignment_1/
```

For example:

```text
http://localhost/PHP/Assignment_1/Q13/q13.php
```
