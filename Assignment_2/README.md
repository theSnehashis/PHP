# Assignment 2 — PHP With MySQL

This folder contains the programs and practical exercises for **Assignment 2** of the PHP With MySQL coursework.

## 📚 Assignment Information

* **Subject:** PHP With MySQL
* **Assignment:** 2
* **Total Questions:** 10
* **Language:** PHP

## 📋 Questions

### Q1 — Numbers in Range 20–50

Write a PHP program to check whether three given integer values are within the range **20–50 inclusive**.

Return:

```text
true
```

if one or more values are within the range.

Otherwise return:

```text
false
```

### Q2 — Number Nearest to 100

Write a PHP program to determine which of two given integers is nearest to the value `100`.

Return:

```text
0
```

if both numbers are equal.

### Q3 — Integer Ranges

Write a PHP program to check whether two given integers are:

* Both within `40–50` inclusive, or
* Both within `50–60` inclusive.

### Q4 — Uppercase Last Three Characters

Write a PHP program to convert the last three characters of a given string to uppercase.

If the string contains fewer than three characters, convert all characters to uppercase.

### Q5 — Count `"aa"` in a String

Write a PHP program to count the occurrences of:

```text
aa
```

in a given string.

The assignment specifies that:

```text
aaa
```

contains two occurrences of `"aa"`.

### Q6 — Search a Number in an Array

Write a PHP program to check whether a specified number is present in a given array of integers.

### Q7 — FizzBuzz String

Write a PHP program to check whether a given string:

* Starts with `"F"`
* Ends with `"B"`

Return:

| Condition                     | Result          |
| ----------------------------- | --------------- |
| Starts with F                 | `Fizz`          |
| Ends with B                   | `Buzz`          |
| Starts with F and ends with B | `FizzBuzz`      |
| Neither condition             | Original string |

### Q8 — Insert String in the Middle

Write a PHP program to insert a given string into the middle of another given string of length 4.

### Q9 — Combine Long and Short Strings

Write a PHP program to create a new string from two given strings:

* One shorter string
* One longer string

The resulting format should be:

```text
long string + short string + long string
```

### Q10 — Left Rotation of Array

Write a PHP program to rotate the elements of a given array of integers of length 4 in the left direction and return the resulting array.

## ▶️ Running the Assignment

Place the repository inside:

```text
C:\xampp\htdocs\PHP
```

Start **Apache** from the XAMPP Control Panel.

Open:

```text
http://localhost/PHP/Assignment_2/
```

For example, to run Question 1:

```text
http://localhost/PHP/Assignment_2/Q1/q1.php
```
